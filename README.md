# AeroCool SkinTech Prototype Demo

This is code for an Innovation Workshop prototype that demonstrates the control system of an electrochromic material used to change emissivity for spacecraft thermal regulation.

It consists of two applications:
- An Android app that controls the signal sent to the material, either manually or based on sensor input such as brightness.  
- A program for the ESP32 microcontroller that rotates a motor with different materials, simulating the electrochromic effect.
